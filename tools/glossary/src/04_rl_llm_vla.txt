# Term | Domain | Definition | refs
A2C / A3C | RL | Advantage actor-critic methods (synchronous / asynchronous) that update a policy using a learned value baseline. | rl
Action (RL) | RL | A choice the agent makes at each step, such as target joint positions. | rl
Action chunking | VLA | Predicting a short sequence of future actions at once rather than one step, for smoother motion and fewer model calls. | vla,il
Actor–critic | RL | A method with an actor (policy) and a critic (value function) trained together. | rl
Advantage | RL | How much better an action is than the average action in a state: Q minus V. | rl
Agent | RL | The learner or decision-maker that interacts with an environment. | rl
Asymmetric actor–critic | RL | The critic sees privileged simulator information while the actor sees only deployable observations. | rl,isaaclab
Behavior cloning (BC) | RL | Supervised learning of a policy from expert demonstrations. | il
Bellman equation | RL | Value of a state equals immediate reward plus discounted value of the next state; the recursion behind value-based RL. | rl
Bootstrapping | RL | Updating a value estimate using another value estimate rather than waiting for the full outcome. | rl
Clipped surrogate objective | RL | PPO's loss that limits how far the new policy's action probabilities may move from the old ones. | rl
Conservative Q-learning (CQL) | RL | An offline RL method that penalises Q-values for actions absent from the data. | rl
Curiosity (intrinsic motivation) | RL | A bonus reward for novel or surprising states that drives exploration. | rl
DAgger | RL | Dataset Aggregation: the learner acts, an expert labels the states it visits, and the data is added for retraining. | il
Decision Transformer | RL | Frames RL as sequence modelling: a transformer predicts actions conditioned on desired return. | rl
Deep Q-network (DQN) | RL | Q-learning with a neural network, a replay buffer and a target network; for discrete actions. | rl
DDPG | RL | Deep deterministic policy gradient: an off-policy actor–critic for continuous actions. | rl
Discount factor | RL | The weight (gamma, 0 to 1) on future versus immediate rewards. | rl
DPO | LLM | Direct Preference Optimization: fine-tunes a model on preference pairs with a simple loss, without a separate reward model. | llm,buildai
Dreamer | RL | A model-based RL family that learns a latent world model and trains a policy on imagined rollouts. | rl
Entropy bonus | RL | A reward for staying random, which encourages exploration and prevents premature convergence. | rl
Environment (RL) | RL | Everything the agent interacts with: the world, robot and simulator. | rl
Episode | RL | One complete run from reset to termination or time limit. | rl
Exploration vs exploitation | RL | The trade-off between trying new actions to learn and using the best known action to score. | rl
GAE | RL | Generalised advantage estimation: blends multi-step returns to trade bias against variance. | rl
GAIL | RL | Generative adversarial imitation learning: a discriminator rewards the agent for looking like the expert. | rl,il
Gymnasium | RL | The standard Python API for RL environments (reset, step, observation and action spaces). | rl,py
HER (hindsight experience replay) | RL | Relabels failed episodes with the goal that was actually reached, creating success signals from failures. | rl
IQL | RL | Implicit Q-learning: an offline RL method that avoids querying out-of-distribution actions. | rl
Inverse reinforcement learning | RL | Inferring the reward function an expert is optimising from its behaviour. | rl,il
MDP | RL | Markov decision process: states, actions, transition probabilities, rewards and a discount. | rl
Model-based RL | RL | Learning a model of the environment's dynamics and using it to plan or train. | rl
Model-free RL | RL | Learning a policy or value function directly from experience without a dynamics model. | rl
MCTS | RL | Monte-Carlo tree search: builds a search tree guided by simulated rollouts; used in AlphaZero. | rl
Multi-agent RL (MARL) | RL | RL with several interacting agents (MAPPO, QMIX, MADDPG). | rl
Off-policy | RL | Learning about one policy from data produced by another; allows replay buffers. | rl
On-policy | RL | Learning only from data generated by the current policy. | rl
Offline RL | RL | Learning a policy from a fixed dataset without further interaction. | rl
PPO | RL | Proximal policy optimization: a stable, simple policy-gradient method with a clipped objective; the default for massively parallel simulation. | rl,isaaclab
Policy | RL | The agent's strategy: a mapping from states to actions (or action probabilities). | rl
Policy gradient | RL | A family of methods that adjust policy parameters to make high-reward actions more likely. | rl
POMDP | RL | A partially observable MDP: the agent sees observations, not the full state. | rl
Potential-based reward shaping | RL | Adding gamma times potential of next state minus potential of current state, which speeds learning without changing the optimal policy. | rl
Prioritised experience replay | RL | Sampling replay-buffer transitions in proportion to how surprising they are. | rl
Q-function | RL | The expected return of taking an action in a state and following the policy afterwards. | rl
Q-learning | RL | An off-policy method that learns Q-values using the maximum over next actions. | rl
Replay buffer | RL | A store of past transitions sampled for training; used by off-policy algorithms. | rl
Reward | RL | The scalar feedback signal the agent tries to maximise. | rl
Reward hacking | RL | The agent exploits a loophole in the reward to score high without doing the intended task. | rl
Reward model | LLM | A network trained on human preferences to score outputs; used in RLHF. | llm
Reward shaping | RL | Designing extra reward terms to make learning easier. | rl,leg
REINFORCE | RL | The basic Monte-Carlo policy-gradient algorithm. | rl
Return | RL | The discounted sum of future rewards from a time step. | rl
Rollout | RL | A trajectory generated by running a policy in an environment. | rl
SAC | RL | Soft actor-critic: an off-policy actor-critic that maximises reward plus entropy; sample-efficient and robust. | rl
SARSA | RL | An on-policy temporal-difference method that updates using the action actually taken next. | rl
State | RL | A description of the situation sufficient to decide what to do next. | rl
Sparse reward | RL | A reward given only on success, making learning hard without shaping or demonstrations. | rl
TD error | RL | Temporal-difference error: reward plus discounted next value minus current value. | rl
TD learning | RL | Learning values by moving estimates toward bootstrapped targets after each step. | rl
TD3 | RL | Twin delayed DDPG: adds twin critics, delayed actor updates and target smoothing for stability. | rl
Temporal difference | RL | See TD learning. | rl
TRPO | RL | Trust-region policy optimization: constrains the KL divergence between old and new policies. | rl
Trajectory | RL | A sequence of states, actions and rewards. | rl
Value function | RL | The expected return from a state under a policy. | rl
Value iteration | RL | A dynamic-programming algorithm that repeatedly applies the Bellman optimality update. | rl,cs
World model | RL | A learned predictor of how the environment will evolve given actions. | rl,vla
Attention sink | LLM | The tendency of models to put large attention weight on the first tokens; exploited by streaming-LLM methods. | llm
Beam search | LLM | Decoding that keeps the k most probable partial sequences at each step. | llm
Chain-of-thought (CoT) | LLM | Prompting or training a model to write out reasoning steps before the answer. | llm
Chinchilla scaling | LLM | The finding that, for a fixed compute budget, parameters and training tokens should grow together (about 20 tokens per parameter). | llm
Constitutional AI | LLM | Aligning models using a written set of principles and AI-generated feedback. | llm
Context window | LLM | The maximum number of tokens a model can attend to at once. | llm
Continuous batching | LLM | Serving technique that adds and removes requests from a running batch at every decoding step. | llm
Function calling (tool use) | LLM | The model outputs structured calls to external tools and reads their results. | llm
GPTQ | LLM | A post-training weight quantisation method that minimises layer output error. | llm,buildai
AWQ | LLM | Activation-aware weight quantisation that protects the most important weights. | llm,buildai
GRPO | LLM | Group relative policy optimization: RL that scores a group of sampled answers against each other, with no critic. | llm,rl
Grouped-query attention (GQA) | LLM | Several query heads share one key/value head, shrinking the KV cache. | llm,arch
Hallucination | LLM | Fluent output that is not grounded in fact or in the provided context. | llm,vla
In-context learning | LLM | Learning a task from examples placed in the prompt, with no weight updates. | llm
Instruction tuning | LLM | Supervised fine-tuning on instruction and response pairs. | llm,buildai
KV cache | LLM | Stored keys and values of past tokens so decoding does not recompute them. | llm
LLM | LLM | Large language model: a very large transformer trained to predict the next token. | llm
LLM-as-judge | LLM | Using a strong model to grade other models' outputs; prone to length and position bias. | llm,evaldeploy
Mixture-of-experts LLM | LLM | See mixture of experts. | llm
Model Context Protocol (MCP) | LLM | An open standard for connecting LLM applications to tools and data sources. | llm
Nucleus (top-p) sampling | LLM | Sampling from the smallest set of tokens whose probabilities add to p. | llm
Paged attention | LLM | A KV-cache memory manager that stores the cache in fixed-size blocks to avoid fragmentation (vLLM). | llm
Perplexity | LLM | The exponential of the average negative log-likelihood per token; lower is better. | llm
Prefix caching | LLM | Reusing the KV cache of a shared prompt prefix across requests. | llm
Prompt injection | LLM | An attack where untrusted text overrides the model's instructions. | llm
Prompt engineering | LLM | Crafting inputs (instructions, examples, format) to get better outputs. | llm
QLoRA | LLM | LoRA fine-tuning on top of a 4-bit quantised base model to save memory. | llm,buildai
Quantisation | LLM | Storing weights or activations in fewer bits (8, 4) to cut memory and latency. | llm,devtools
RAG | LLM | Retrieval-augmented generation: retrieve relevant documents and give them to the model as context. | llm
ReAct | LLM | An agent pattern alternating reasoning steps and tool actions. | llm
RLHF | LLM | Reinforcement learning from human feedback: train a reward model from preferences, then optimise the policy against it. | llm,rl
RLVR | LLM | Reinforcement learning with verifiable rewards (math answers, unit tests). | llm,rl
Scaling laws | LLM | Empirical power-law relations between loss and model size, data and compute. | llm
Self-consistency | LLM | Sampling several reasoning paths and taking the most common answer. | llm
Speculative decoding | LLM | A small model drafts several tokens and the large model verifies them in one pass. | llm
Supervised fine-tuning (SFT) | LLM | Training a pretrained model on curated input–output examples. | llm,buildai
System prompt | LLM | Instructions that set the model's role and rules before the user's message. | llm
Temperature (sampling) | LLM | Controls randomness in sampling; lower is more deterministic. | llm
Token | LLM | The unit of text a model reads and writes: a word, word piece or byte sequence. | llm
Tokeniser | LLM | The component that converts text to token ids and back (BPE, SentencePiece). | llm

Vector database | LLM | A store that indexes embeddings for fast nearest-neighbour search (FAISS, pgvector, Milvus). | llm
vLLM | LLM | A high-throughput LLM serving engine using paged attention and continuous batching. | llm,buildai
