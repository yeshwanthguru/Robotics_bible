# 🤖 Robotics & AI Bible

> A lifelong handbook, dictionary and Q&A for **ML → DL → RL → LLM/VLM/VLA → Quantum → Physical AI → Robotics → Software → Simulation.** Search anything with Ctrl+K.

**📖 Read it online: https://yeshwanthguru.github.io/Robotics_bible/**

Every chapter is written twice over: **plain English first** (a 30-second summary, an analogy and pictures), **then the technical depth** (equations always followed by an "in words" line, code, tables), and it ends with **interview Q&A** that gives a simple answer and a deeper follow-up. There are 60+ diagrams.

## Run locally

```bash
npm ci
npm start          # http://localhost:3000/Robotics_bible/
npm run build      # static site in ./build
```

Requires Node 18+.

Regenerate the figures (optional): `pip install matplotlib numpy && python tools/figures/make_all.py`

Add or edit dictionary terms: edit `tools/glossary/src/*.txt` (one line per term: `Term | Domain | Definition | ref1,ref2`) then run `python tools/glossary/build_glossary.py`.

## Project layout

```
docs/                numbered folders = sidebar order (each has _category_.json)
src/pages/index.js   redirects the home page to /docs/
static/img/fig/      diagrams (SVG), generated by tools/figures/
tools/figures/       matplotlib scripts that regenerate every figure
tools/glossary/      dictionary source (src/*.txt) and build_glossary.py that writes docs/glossary/
examples/            runnable PyTorch scripts: tiny GPT, tiny VLM, tiny VLA (see Build It Yourself)
docusaurus.config.js site config (KaTeX math, Mermaid diagrams, local search)
.github/workflows/   GitHub Pages deployment
```

Writing conventions: math with `$…$` / `$$…$$` (KaTeX), diagrams with fenced ` ```mermaid ` blocks, `.md` files parsed as plain CommonMark (no MDX), so curly braces in prose are safe.

## Deployment

Pushes to `main` build and deploy via GitHub Actions. One-time setup: **Settings → Pages → Source: GitHub Actions**.
