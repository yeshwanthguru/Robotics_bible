# Glossary

**ACT** Action Chunking Transformer · **ADE/FDE** displacement errors · **AMCL** adaptive Monte Carlo localization · **AMR** autonomous mobile robot · **BA** bundle adjustment · **BC** behavior cloning · **BT** behavior tree · **CBF** control barrier function · **CoM/CoP** center of mass / pressure · **CQL** conservative Q-learning · **DDS** data distribution service · **DH** Denavit–Hartenberg · **DMP** dynamic movement primitive · **DoF** degrees of freedom · **DR** domain randomization · **EKF** extended Kalman filter · **ESDF/TSDF** (Euclidean) signed distance field · **FK/IK** forward/inverse kinematics · **FOC** field-oriented control · **GAE** generalized advantage estimation · **GCS** graph of convex sets · **GRPO** group relative policy optimization · **HIL** hardware- or human-in-the-loop · **ICP** iterative closest point · **IMU** inertial measurement unit · **InEKF** invariant EKF · **LIPM** linear inverted pendulum model · **LIO/VIO** LiDAR/visual-inertial odometry · **LoRA** low-rank adaptation · **MoE** mixture of experts · **MPC/MPPI** model predictive control / path integral · **NISQ** noisy intermediate-scale quantum · **NITROS** NVIDIA Isaac Transport for ROS · **OMPL** open motion planning library · **PDDL** planning domain definition language · **PEFT** parameter-efficient fine-tuning · **PoE** product of exponentials · **PPO/SAC/TD3** RL algorithms · **QAOA/VQE** variational quantum algorithms · **QoS** quality of service · **RAG** retrieval-augmented generation · **REP** ROS enhancement proposal · **RMW** ROS middleware · **RNEA** recursive Newton–Euler algorithm · **SEA** series elastic actuator · **SLAM** simultaneous localization and mapping · **TAMP** task and motion planning · **TF** transform tree · **URDF/SDF/MJCF/USD** robot/scene formats · **VLA/VLM** vision-language-(action) model · **WBC** whole-body control · **ZMP** zero-moment point
